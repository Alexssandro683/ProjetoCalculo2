# 🚀 Simulador Futurista de Veículos

Sistema interativo desenvolvido em Python e Streamlit para simulação matemática de veículos.

## Funcionalidades

- Controle de velocidade
- Controle de aceleração
- Telemetria em tempo real
- Simulação visual animada
- Gráficos matemáticos
- Indicadores de combustível e autonomia

## Instalação

```bash
git clone https://github.com/seuusuario/simulador-futurista.git
cd simulador-futurista

pip install -r requirements.txt

streamlit run app.py
```

## Tecnologias

- Python
- Streamlit
- Matplotlib
- HTML/CSS
- JavaScript
